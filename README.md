## Deploy on Vercel

1. Create a GitHub repository named `jainam-portfolio`.
2. Upload `index.html`, `style.css`, `script.js`, and `README.md`.
3. Push the project to GitHub.
4. Sign in to Vercel.
5. Click **Add New → Project**.
6. Import the `jainam-portfolio` GitHub repository.
7. For this static website, no build command is required.
8. Click **Deploy**.
9. Vercel will give you a live `.vercel.app` URL.

Every future push to the connected GitHub repository can automatically trigger a new Vercel deployment.
